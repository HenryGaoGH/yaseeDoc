# 异常&信息对照表

:::danger
本错误涵盖SDK 上报错误 和 过程信息; 
理论上:
1. 错误 建议中断流程
2. 信息可 纯做 业务提示

具体业务流程可业务端自行调整
:::

## 查询规则

### 异常路由（`ErrorTmd.getError`）

| LocalCheckEnum | 检测项 | step 条件 | 数据表 |
| --- | --- | --- | --- |
| `Bp` | 血压 | 任意 | `_bp` |
| `Ch` | 荧光 | 任意 | `_ch` |
| `To` / `Tot` | 三合一（血糖、尿酸、血酮） | 任意 | `_tone` |
| `Tp` | 体温 | 任意 | `_tp` |
| `Bf` | 血脂 | 任意 | `_bf` |
| `Ub` | 尿液 | 任意 | `_ub` |
| `Cgm` | CGM | 任意 | `_cgm` |
| `Gh` | 糖化 | 任意 | `_gh` |
| `Hs` | 心/肺音 | 任意 | `_hs` |
| `Ch_Ht` | 荧光（汉唐） | `step == CmdType.error` | `_ch_ct_err` |
| `Ch_Ht` | 荧光（汉唐） | 其他 step | `_ch_ct` |

映射中不存在对应 code，或检测项未进入以上分支时，返回：**未知错误 / 无操作建议**。

### 信息路由（`MessageTmd.getMsg`）

| LocalCheckEnum | 检测项 | step 条件 | 数据表 |
| --- | --- | --- | --- |
| `Ch_Ht` | 荧光（汉唐） | `step == CmdType.message` | `_ch_ct_status` |
| `Ch_Ht` | 荧光（汉唐） | 其他 step | `_ch_ct` |
| `Bf` | 血脂 | `step == CmdType.join` | `_bfJoin` |
| `Bf` | 血脂 | 其他 step | `_bf` |
| `Ub` | 尿液 | 任意 | `_ub` |
| `Gh` | 糖化 | 任意 | `_gh` |
| `Cgm` | CGM | 任意 | `_cgm` |

映射中不存在对应 code，或检测项未进入以上分支时，返回：**未知信息 / 无操作建议**。

## 数据源注意事项

### CGM 异常表存在重复键

`ErrorTmd._cgm` 连续多次调用 `put(0x03, ...)`。Java `HashMap` 对相同键采用后写覆盖前写，因此运行时 `0x03` 最终只会返回 **超出测量时间 / 请同步数据; 并丢弃**。上方异常表按运行时最终有效结果展示。被覆盖的源码条目如下：

| code（16进制） | code（10进制） | 描述 | 操作建议 |
| --- | --- | --- | --- |
| `0x03` | 3 | 过期试纸状态 | 请更换试纸;过期试纸状态 |
| `0x03` | 3 | 极化异常 | 极化异常 |
| `0x03` | 3 | 试纸设备测试异常 | 试纸设备测试异常 |
| `0x03` | 3 | Code不支持 | Code不支持 |

### 血脂 join 查询码与返回 code 不一致

`MessageTmd._bfJoin` 中，查询键 `0x80`–`0x85` 对应的 `ErrorObj.code` 分别是 `0x00`–`0x05`。因此使用这些高位查询码时，返回对象中的 code 与查询码不同；上方表格已分别展示二者，不应将返回 code 误认为原始查询码。
